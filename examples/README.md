# Demo assets

`baseline.png` and `candidate.png` are deterministic, synthetic dashboard screenshots generated by
`scripts/generate_demo_assets.py`. They contain:

1. a harmless card-shadow adjustment;
2. a missing refresh glyph with its button bounds preserved; and
3. a clipped Chinese primary-action label.

Regenerate them with:

```bash
python scripts/generate_demo_assets.py
```

`scenarios.yaml` documents the planned Playwright + rootless Podman capture contract. The 0.1 CLI
compares already-captured screenshot pairs and does not execute that file yet.
